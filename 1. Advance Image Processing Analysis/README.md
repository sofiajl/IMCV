
# 1. Advance Image Processing Analysis

This directory contains my individual implementations and experimental notebooks for the laboratory cases in the **Advance Image Processing Analysis** module.


## 📖 Course Overview & Objectives

This unit addressed advanced methodologies in digital image processing and analysis. The core objectives include:
- Advanced digital image denoising
- Restoration
- Probabilistic modeling
- Variational segmentation
- Deep generative image enhancement

More details: https://imcv.eu/guide/2023-2024/aipa/

## 🧪 Laboratory Assignments

| Lab / Notebook | Topic & Methodologies |
| :--- | :--- |
| **`Lab1_ImageDenoising_TotalVariation.ipynb`** | Total Variation (TV) regularization, ROF model, edge-preserving denoising, energy minimization. |
| **`Lab2_ImageDenoising_AnisotropicDiffusion.ipynb`** | Perona-Malik anisotropic diffusion, non-linear PDE filtering, gradient-based conduction coefficients. |
| **`Lab3_MarkovRandomFields.ipynb`** | Markov Random Fields (MRFs), energy formulation (data term + smoothness term), Graph Cuts, MAP estimation for segmentation. |
| **`Lab4-Deformable models`** | Active Contour Models (Snakes), internal/external energy formulations, curve evolution, Level-Set segmentation. |
| **`Lab5_Image Segmentation.ipynb`** | Advanced segmentation frameworks, color/texture feature spaces, region-based & boundary-based segmentation techniques. |
| **`Lab6_Image Super Resolution&Denoising.ipynb`** | Super-resolution reconstruction, frequency domain upsampling, learning-based image restoration, PSNR/SSIM evaluation. |
| **`Lab7_Image Colorization.ipynb`** | Automatic image colorization, color space transformations (Lab/HSV), guidance-based and deep learning colorization methods. |
