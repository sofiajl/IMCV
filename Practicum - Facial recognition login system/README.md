# Practicum - Facial Recognition Login System

This directory contains the codebase and technical report for a **facial recognition login system** developed as part of an academic practicum in collaboration with XING. The project explores State-of-the-Art (SoTA) deep learning methods trained on synthetic data (DCFace dataset) and evaluated on real face data (CASIA-WebFace dataset).


## 📌 Overview

The **Facial Recognition Login System** explores privacy-preserving authentication mechanisms by leveraging synthetic training data. By training deep learning models on synthetic face images generated by **DCFace** (Dual Condition Face Generator) and evaluating performance on real-world datasets such as **CASIA-WebFace**, this project assesses the viability of synthetic-to-real transfer for biometrics, reducing dependence on real biometric data collection during training.

The system extracts compact feature embeddings from input face images, projects them into a low-dimensional vector space, and uses distance or angular metrics to verify user identity for authentication tasks.

## ⚙️ Architecture & Method

The project implements and compares three main deep feature learning architectures and loss formulations:

```text
                     ┌───────────────────────────────┐
                     │       Input Face Image        │
                     └───────────────┬───────────────┘
                                     │
                                     ▼
                     ┌───────────────────────────────┐
                     │   Convolutional Backbone      │
                     │      (e.g., DenseNet121)      │
                     └───────────────┬───────────────┘
                                     │
                                     ▼
                     ┌───────────────────────────────┐
                     │    Low-Dimensional Embedding  │
                     └───────────────┬───────────────┘
                                     │
        ┌────────────────────────────┼────────────────────────────┐
        ▼                            ▼                            ▼
┌──────────────┐             ┌──────────────┐             ┌──────────────┐
│ Triplet Loss │             │  Semi-Hard   │             │   ArcFace    │
│ (Euclidean)  │             │ Triplet Loss │             │   (Margin)   │
└──────────────┘             └──────────────┘             └──────────────┘
```

## 📁 Repository Structure
```text
├── main/
│   ├── BatchGeneratorArcFace.py             # Custom batch generator for ArcFace training
│   ├── BatchGeneratorTripletLoss.py         # Custom batch generator producing (Anchor, Positive, Negative) triplets
│   ├── BatchGeneratorTripletSemiHardLoss.py # Batch generator for online semi-hard triplet mining (Anchor, Positive pairs)
│   └── Metrics.py                           # Evaluation metrics (Accuracy, Precision, Recall, FAR, FRR)
├── Practicum-Report.pdf                     # Academic report detailing methods, setup, and experimental results
├── Test_data.ipynb                          # Evaluation script for testing model performance on test pairs
├── TripletLoss.ipynb                        # Initial implementation and training with standard Triplet Loss
├── TripletLoss_v2.ipynb                     # Fine-tuned or alternative iteration of standard Triplet Loss
├── TripletSemiHard.ipynb                    # Training pipeline using TensorFlow's Semi-Hard Triplet Loss
├── TripletSemiHard_v2.ipynb                 # Refined iteration of the Semi-Hard Triplet Loss training pipeline
├── TripletSemiHard-RealData.ipynb           # Real-world testing notebook evaluating Semi-Hard models on personal/real images
└── pred_experiments.ipynb                   # Experimental notebook for feature embedding visualization and predictions
```
